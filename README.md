# 📊 Growth Mindset DataForge Pro

## 🚀 Overview
**Growth Mindset DataForge Pro** is a powerful and interactive **Streamlit-based web application** designed to help users **analyze, visualize, and clean their data** while fostering a **growth mindset**. This tool is perfect for learners, data enthusiasts, and professionals who want to improve their data skills and adopt a growth mindset in their learning journey.

---

## 🌟 Key Features

### 📊 Data Visualization
- **Multiple Chart Types:** Bar Charts, Line Charts, Scatter Plots, Histograms, Pie Charts, Box Plots, and Heatmaps.
- **Interactive Visuals:** Dynamic visualizations using **Plotly** for an engaging experience.
- **Customizable Axes:** Choose specific columns for X and Y axes to tailor your visualizations.

### 🛠️ Data Cleaning Tools
- **Remove Duplicates:** Eliminate duplicate rows from your dataset.
- **Drop Columns:** Select and drop unnecessary columns.
- **Fill Missing Values:** Automatically fill missing numeric values with column means.
- **Handle Categorical Data:** Replace missing categorical values with "Unknown".

### 📂 File Upload and Conversion
- **Multi-File Support:** Upload multiple CSV or Excel files simultaneously.
- **File Conversion:** Convert datasets to CSV, Excel, or JSON formats.
- **Preview Data:** View a snapshot of your uploaded files before processing.

### 📝 Reflection Journal
- **Track Progress:** Log challenges, lessons learned, and improvement plans.
- **Save Reflections:** Store reflections to monitor growth over time.

### 📈 Progress Tracker
- **Task Completion:** Track the number of completed tasks and reflections written.
- **Visualize Progress:** View progress using an interactive bar chart.

### 🎯 Learning Goals
- **Set Goals:** Define learning objectives to stay focused.
- **Goal Tracking:** Monitor your journey toward achieving these goals.

### 🔍 Advanced Data Analysis
- **Data Summary:** View a statistical summary of your dataset.
- **Correlation Matrix:** Analyze relationships between numeric columns.
- **Missing Values Analysis:** Identify and analyze missing data.
- **Outliers Analysis:** Detect and visualize outliers in numeric data.

### 🎨 App Design
- **Dark Mode Aesthetics:** Sleek and modern interface with dark mode.
- **Custom CSS:** Enhanced visuals with rounded corners, shadows, and transparent backgrounds.
- **User-Friendly Layout:** Intuitive sidebar navigation and well-structured sections.

## 🛠️ How to Use

### 1️⃣ **Upload Your Data**
- Use the file uploader to upload **CSV** or **Excel** files.
- Upload and process multiple files at once.

### 2️⃣ **Clean Your Data**
- Remove duplicates, drop columns, fill missing values, and handle categorical data.

### 3️⃣ **Visualize Your Data**
- Choose visualization types and customize axes for interactive charts.

### 4️⃣ **Analyze Your Data**
- Explore data summaries, correlation matrices, missing values, and outliers.

### 5️⃣ **Convert and Download**
- Convert your dataset to **CSV**, **Excel**, or **JSON** formats and download it.

### 6️⃣ **Track Your Growth**
- Use the **Reflection Journal** and **Progress Tracker** to monitor your journey.
- Set and achieve learning goals.
